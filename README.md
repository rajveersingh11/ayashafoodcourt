# 🍲 Ayanshi Food Court — 3D Interactive Dining Web Application

> **Homestyle Pure Vegetarian Meals • Interactive 3D Experience • Mamura Sector 66 Noida**

An interactive, high-performance 3D web application for **Ayanshi Food Court** built with **React**, **Three.js**, **React Three Fiber**, and **Tailwind CSS**.

🌐 **Live URL**: [https://rajveersingh11.github.io/ayashafoodcourt/](https://rajveersingh11.github.io/ayashafoodcourt/)

---

## ✨ Features

- **Interactive 3D Hero Showcase**:
  - Centerpiece Royal Indian Thali rendered with photorealistic PBR materials (polished brass and stainless steel).
  - Volumetric rising steam particle physics and floating aromatic spice specks.
  - 360° mouse drag/touch rotation, auto-spin toggle, zoom controls, and interactive 3D dish tags.

- **Interactive 3D "Thali Studio" (Customizer)**:
  - Assemble custom thalis in real-time 3D (Platter, Dal, Main Sabzi, Breads, Rice, and Extras).
  - Dynamic price ticker and live 3D visual updates.
  - Direct WhatsApp order generator and confetti celebration upon adding to cart.

- **360° Interactive Dish Inspector**:
  - Modal inspection for signature curries, naans, rotis, and desserts.
  - Portion sizing options (Half Plate / Full Plate) with instant order adding.

- **Full E-Commerce Cart & WhatsApp Dispatch**:
  - Slide-over cart drawer with Free Delivery threshold meter (Free within 2 km on ₹350+ orders).
  - Order type selector: Doorstep Delivery vs Takeaway/Pickup.
  - Formatted WhatsApp order generator sending directly to `+91 82717 54563`.
  - Direct click-to-call shortcuts (`82717 54563` & `78277 98007`).

- **Procedural Culinary Ambience**:
  - Web Audio API synthesizer generating subtle simmering kitchen sizzle without external audio downloads.

- **Mobile First & PWA Ready**:
  - Mobile bottom navigation bar for quick ordering and calling.
  - Clamped device pixel ratio (DPR) for smooth 60 FPS on mobile GPUs.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Styling**: Tailwind CSS
- **Icons & FX**: Lucide React, Canvas Confetti
- **Audio**: Web Audio API (Synthesized procedurally)
- **Deployment**: GitHub Actions CI/CD to GitHub Pages

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)

### Installation

```bash
# 1. Clone repository
git clone https://github.com/rajveersingh11/ayashafoodcourt.git

# 2. Navigate into project
cd ayashafoodcourt

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
```
